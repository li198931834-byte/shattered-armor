# 碎甲成原 2.2 / SHATTERED ARMOR

完全离线的 30 关纵向射击战役。驾驶 XF-07“雪隼”战机，击落小型机群赚经验，通过升级构筑火力，在每关最后挑战大型 Boss。

## 启动

双击完整包中的 `碎甲成原.html`，使用 Edge、Chrome 等现代浏览器打开，无需安装、无需联网。“开始新战役”从第一关出发；已有进度时可点“继续第 X 关”。

## 操作

| 按键 | 作用 |
| --- | --- |
| 方向键 / WASD | 移动 |
| Shift | 精细减速 |
| X / K | 无敌冲刺，初始冷却 2.5 秒 |
| E | 清除敌弹和光束，并伤害敌人 |
| 1 / 2 / 3 | 选择本关升级强化 |
| P / Esc | 暂停 / 继续 |
| 空格 / J | 手动射击，默认已自动开火 |

也可以按住战场拖动飞机，鼠标右键冲刺。手机在战场任意位置按住并滑动即可移动：滑动位移放大 1.5 倍，跟随速度为 800 游戏像素/秒，比 2.1.1 版提高约 29%，抬手立即停止，重新按下不会拉动飞机。使用下方冲刺、清屏按钮。只有飞机中央橙色点是受击判定，半径 4 个游戏像素。推荐电脑键盘挑战噩梦。

## 30 关与敌人

每关先对抗多波有规律的敌机编队：第 1–5 关 4 波、第 6–10 关 5 波、第 11–15 关 6 波、第 16–20 关 7 波、第 21–25 关 8 波、第 26–30 关 9 波。第一关共有 78 架小怪，第 30 关共有 405 架；全战役总计 6691 架。前五关最多同时在场 8–9 架，后续逐步增加，按小队分批增援。敌机分侦察、突击、重装三类，分别有直射、扇射等攻击。

每批敌机被击落或飞离战场后进入下一批。本关所有波次结束后清除残留弹幕，出现 2.5 秒大型敌机警报，然后才进入关底 Boss 战。Boss 有三阶段攻击，转阶段短暂无敌并清空敌弹。

30 关拥有各自名称，使用三种 Boss 攻击范式，按关数增加耐久、弹速和攻击频率。每个 Boss 的血量至少为 2.1 版同关 Boss 的三倍，并且后关至少比前关多 8%，不会因攻击范式轮换而降低；第一关血量 6900，第三十关血量 309138。小怪耐久、航速和攻击压力逐关上升。第 10、20、30 关为强化关底。第三十关 Boss 被击破才算完整通关，前三关之后不会提前结束。

## 每关独立成长

进入每一关时，等级回到 LV.1，经验和本关总经验清零，所有强化重置。飞机恢复双发主炮、基础伤害与攻速，装甲恢复该难度的初始上限，清屏弹恢复 3 发，护盾、充能和冲刺冷却重置。

通关结算后可直接点击进入下一关；本关强化不会带到下一关。累计得分、战斗时间、击落数、关卡解锁和最佳星级继续保留。失败重试与选关也从该关基础配置开始。

第一关仍采用慢速、规律的早期弹道，按小队增援。波次增加不会一次性刷出整关敌机；临近玩家区域的小怪停止射击，开火前亮起提示。首次升级需要 60 经验，后续等级需求逐步提高。

## 经验升级

击落侦察、突击、重装敌机分别获得 6、10、16 点基础经验；第 11–20 关经验翻倍，第 21–30 关为三倍。经验自动到账，不必拾取。飞离战场或撞击消失的敌机不给经验。

每升一级暂停战斗，从三项强化中选择一项，选择后立即继续。连续升级时依次选卡，溢出经验会保留。只要弹数、伤害、攻速仍有未满级项目，每次升级至少提供其中一项。满级选项不再出现。

| 强化 | 每级效果 | 上限 |
| --- | --- | --- |
| 多重弹仓 | 主炮每轮 +2 枚完整伤害弹，从 2 发成长到 12 发 | 5 级 |
| 过载弹芯 | 单发伤害 +2.8，相当于初始伤害的 20% | 20 级 |
| 高速扳机 | 射击间隔乘以 0.9，逐级叠加 | 8 级 |
| 分形弹道 | 每轮增加 2 枚斜向弹，每枚为主炮伤害的 45% | 3 级 |
| 追猎卫星 | 增加 1 架自动发射追踪弹的卫星，伤害随主炮强化成长 | 4 级 |
| 相位跃迁 | 冲刺冷却乘以 0.82，保护增加 0.05 秒 | 4 级 |
| 复合装甲 | 装甲上限 +1，立即修复 2 格 | 7 级 |
| 磁暴共振 | 清屏伤害 +120，充能所需擦弹 -3，最低 6 次 | 6 级 |
| 偏转护盾 | 本关护盾上限 +1 层，立即补充一层 | 2 级 |

大部分项目满级后会出现战地补给、紧急维修、弹药空投，避免后期升级没有选项。强化只对本关生效；通关后直接进入下一关，等级、经验、强化和补给恢复基础配置。

等级、经验进度、击落数位于战场下方；本关强化、弹数、单发伤害与攻速位于侧边。手机上这些信息显示在战场下方。卫星自动开火，不受主炮自动开火开关影响。

## 本机账号、选关与星级

右上角可以注册或登录本机账号。账号、关卡、星级和关首进度只保存在当前浏览器，不跨设备同步；密码不以明文保存。新账号会继承当前游客的已保存进度。退出账号后回到游客档案，各账号之后的进度独立保存。

通过右上角“关卡 ★”可以查看 30 关的解锁状态和最佳星级。失败后还可直接点击“返回关卡列表”，选择已解锁关卡从关首重试；未解锁关卡不能跳过。标准与噩梦分别记录星级。

通关时按剩余装甲占上限的比例评分：至少 75% 为三星；低于 75% 但至少 2/3 为二星；低于 2/3 但至少 50% 为一星；低于 50% 为零星。零星也算通关并解锁后续关卡。重玩只提高最佳星级，不会降低已有星级。评分发生在进入下一关恢复基础配置之前。

## 存档与重试

新战役及进入下一关时自动保存关首。刷新后点“继续第 X 关”恢复本关开头，失败也可从关首重试：均从 LV.1、零经验、零强化、初始装甲与 3 发清屏弹开始。旧版存档保留当前关数和累计记录，携带的旧强化按新规则清除；账号和最佳星级继续保留。

点击“开始新战役”会覆盖旧战役进度。练习模式不会覆盖正式战役存档。存档与纪录只存在当前浏览器中，清理浏览器数据或换浏览器可能丢失。30 关版本使用单独的战役纪录，与旧三关版本分开。

## 模式与其他

标准战役有 5 格初始装甲；噩梦有 3 格，弹幕更快。练习模式可直接选 30 个关底中的任意一场、无限复活，打完当前 Boss 即结束，不计分。

清屏弹最多持有 5 发，每次初始需要 24 次擦弹补充一发，可通过强化降低。受伤后约有 1.6 秒保护。切走页面或窗口失焦会自动暂停。音效默认关闭，右上角 ♪ 可开启；所有音效由浏览器合成。系统开启“减少动态效果”时会减少震屏、闪光和背景动态。

## 源码与验证

没有运行依赖和外部资源请求。源码目录内运行 `npm run serve`，再访问 http://127.0.0.1:8096/；模块源码调试地址为 http://127.0.0.1:8096/dist/。

- `npm test`：经验单次发放、连续升级、选卡冻结、弹数/伤害/攻速生效、30 关推进、存档与战斗检查。
- `npm run build`：打包成单文件离线 HTML。
- `tests/browser.test.mjs`：本机 Edge + Playwright 交互验收，包含键盘、清屏击杀升级、手机选卡、30 关界面流程、刷新继续与离线文件；需先启动本机预览并安装 Playwright；使用系统浏览器时通过 BROWSER_EXECUTABLE_PATH 指定路径。
- `tests/accounts.browser.mjs`：本机注册、登录、错误密码、账号进度隔离、选关与星级验收。
- `tests/campaign.browser.mjs`：密集机群、经验选卡与 Boss 入场衔接、飞机外观截图检查。

自动化通过程序触发击杀验证整个战役的状态衔接，不代表真人完成噩梦 30 关通关。
